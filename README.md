|---|---|---|---|---|---|
| 01 | 2026-11-01 | [영남대천마캡스톤](01_202611_영남대천마캡스톤/00_공모요강.md) | 2026 AI 캡스톤디자인 경진대회 | 제외 | 참가 불가 (지역 자격) |

상태: 준비중 → 제출완료 → 결과대기 → 종료 (참가 불가는 "제외")

## 폴더 이름 규칙

`번호_마감년월_별칭` (예: `01_202611_영남대천마캡스톤`)

- 번호: 등록 순서 (01, 02, ...)
- 마감년월: 접수 마감 기준 `YYYYMM`
- 별칭: 부르기 쉬운 이름, 공백 없이 작성
- 정식 명칭은 위 목록과 각 폴더의 `00_공모요강.md`에 기록

## 후보 등록 시 먼저 확인할 것

- 참가 자격: 지역(거주지·학교·직장 기준), 신분(학생/일반인), 팀 구성

- `00_공모요강.md` — 요강 요약, 일정, 체크리스트

- `02_제출물/` — 제출 서류 초안
- `03_결과.md` — 제출 내역, 심사 결과, 회고
- `99_원본자료/` — 공고문 첨부파일 원본
