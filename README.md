## 폴더 이름 규칙

`번호_마감년월_별칭` (예: `01_202611_영남대천마캡스톤`)

- 번호: 등록 순서 (01, 02, ...)
- 마감년월: 접수 마감 기준 `YYYYMM`
- 별칭: 부르기 쉬운 이름, 공백 없이 작성
- 정식 명칭은 위 목록과 각 폴더의 `00_공모요강.md`에 기록
