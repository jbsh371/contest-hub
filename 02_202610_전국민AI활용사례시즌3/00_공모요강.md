## 어디서, 어떻게 접수하나

**접수 흐름 (2026-10-19 사용자 확인)**
[전국민 AI 경진대회 홈페이지](https://aichallenge4all.or.kr) 메뉴 **참가 트랙** → **AI 활용 사례 공모전** 클릭 → [공모전 소개 페이지](https://aichallenge4all.or.kr/competitions/case-contest) → **참가신청** → [접수 페이지](https://ai.software.kr/contest/apply)

| 단계 | 내용 |
|---|---|
| 1. 통합 홈페이지 | https://aichallenge4all.or.kr → 메뉴 "참가 트랙" → "AI 활용 사례 공모전" |
| 2. 공모전 소개 페이지 | https://aichallenge4all.or.kr/competitions/case-contest — 안내 PDF, 참가신청 버튼 |
| 3. 접수 페이지 | https://ai.software.kr/contest/apply (2026-10-19 접수 열려 있음 확인) |
| 4. 약관 동의 | 개인정보 수집·이용, 저작권 및 활용 동의, 본인 사례 확인 및 책임 서약 (필수) |
| 5. 신청서 작성 | 공모 분야(선택) → 사례 제목 → 닉네임(공개 게시판 표시, 랜덤 가능) → 비밀번호 → 이름·휴대전화·이메일 → 활용한 AI 도구 → 한 줄 소개 → 활용 사례 내용 (모두 필수, 글자수 제한은 화면에서 확인) |
| 6. 첨부 | PDF·JPG·PNG·MP4, 개당 20MB, 최대 5개 |
| 7. 제출 | 제출한 사례는 사례 게시판(https://ai.software.kr/board?brdTp=CONTEST)에 올라감 |

- 회원가입·로그인은 없고, 글마다 비밀번호를 정한다. 제출 뒤에도 비밀번호로 수정 가능.
- 글자 수 제한 (접수 페이지 HTML, 2026-10-20): 제목 200자, 활용한 AI 도구 500자, 한 줄 소개 200자, 활용 사례 내용은 제한 표시 없음.
- 활용 사례 내용은 **일반 텍스트 상자**라 표·굵은 글씨가 안 된다. 자세한 분석은 [참고_지난시즌분석.md](참고_지난시즌분석.md).
- 활용 사례 내용 작성 가이드 (접수 페이지 원문, 2026-10-23 다시 확인): "① 어떤 상황에서 AI를 활용했나요? ② 어떤 AI를 어떻게 활용했나요? ③ 활용 결과 어떤 변화가 있었나요? ④ 나만의 방식 또는 개선 포인트는 무엇인가요? ⑤ 다른 사람도 따라 할 수 있나요?" 시즌2 수상작(work/501, 07-07)도 이 다섯 질문을 그대로 소제목으로 씀. (이전 기록 "① 상황 ② 사용한 AI와 활용 방법 ③ 결과 변화 ④ 나만의 방식 ⑤ 재현 가능성"은 줄인 이름이었고, ④의 "개선 포인트"가 빠져 있었다)
- 칸별 안내 문구 (사용자 화면 캡처, 2026-10-23 18:03. 웹 가져오기로는 안 보였음):
  - 공모 분야: "업무 생산성 개선을 위한 AI 활용"
  - 사례 제목: "AI를 활용한 사례를 한 문장으로 표현해주세요"
  - 활용한 AI 도구: 한 줄 입력칸, "예: ChatGPT, Upstage Solar, 뤼튼, 코파일럿 등" → 도구 이름을 적는 칸
  - 한 줄 소개: "사례를 짧게 소개해주세요 (목록에 노출됩니다)"
  - 활용 사례 내용: 큰 입력칸에 다섯 질문이 회색 안내 글로 들어 있음
  - 화면 순서: 약관 동의 → 1쪽(분야, 제목, 닉네임, 비밀번호, 이름, 휴대전화, 이메일, AI 도구) → "세부 사례 작성하기" → 2쪽(한 줄 소개, 작성 가이드, 활용 사례 내용, 파일 첨부) → "신청서 제출하기"
- 약관 "공모전 참여 유의사항" 2항: 기존에 알려진 AI 활용 방식이라도 제안자의 실제 업무 등에 적용한 경험과 자신만의 방식으로 재해석·개선된 사례를 포함해 인정한다
- 다른 참가자 사례를 사례 게시판에서 미리 볼 수 있다.

| ② AI 활용 적정성 | 25 | AI 활용 목적의 명확성 / AI 도구·기술 선택의 적절성 / 활용 절차의 구체성, 결과 활용의 적절성 |
| ③ 창의성·실용성 | **30** | 아이디어의 참신성·차별성 / **실제 적용 가능성, 재현 용이성** / 기대효과의 구체성, 확산 가능성 |
| ④ 윤리·책임성 | 25 | 개인정보 보호, 저작권, 자료 활용(참고표시) / 부정확한 정보·편향·유해 표현 여부 / 건전하고 책임 있는 AI 활용 |

## 유의사항
- 저작권은 제안자에게 있음. 주최 측은 공익 목적(홍보, 교육, 정책)으로 복제·배포·편집 가능
- 인정: 기존에 알려진 방식이라도 **실제 적용 경험 + 자신만의 방식으로 재해석·개선**한 사례
- 불인정: 타인 사례 복제, 실제 적용 없는 단순 아이디어, 출처 없는 타인 콘텐츠, 타 공모전 수상작, 차별성·개인화 없는 사례
- 표절·허위 시 심사 제외, 수상 후에도 취소·상금 환수, 민·형사 책임
- 생성형 AI 사용 허용. 저작권·초상권·개인정보 책임은 제안자. 주최 측이 AI 도구·활용 방식 설명을 요구할 수 있음
- 여러 분야 중복 응모 가능, **최종 수상은 1인 1건**
- 수상자 실명, 사례 제목·주요 내용 공개 가능
- 개인정보는 종료 후 3년 보유
