# 과제: 두 초안(A, B)을 평가 기준으로 독립 검토하기

2026 전국민 AI 활용 사례 공모전 시즌3, 업무 생산성 분야에 낼 사례글이다. 마감 10-31, 제출 목표 10-29. 같은 사실 목록(01)과 같은 작성 기준(04)으로 서로 모르는 두 작성자가 따로 쓴 초안 A(06)와 초안 B(07)가 있다. 어느 초안을 바탕으로 삼고, 다른 초안에서 무엇을 가져올지 독립적으로 판단해 달라.

## 읽을 것 (이 여덟 파일만)
01_사실목록.md (실제로 한 일, 유일한 사실 근거) / 02_공모요강.md (평가 기준·접수 칸) / 03_경쟁현황.md / 04_작성기준.md (두 초안이 따른 기준) / 05_실제요청문장.md (실제 대화 원문) / 06_초안A.md / 07_초안B.md / 08_과제.md(이 파일)
다른 파일·폴더·웹은 보지 않는다. 파일을 만들거나 고치지 않는다 (지정한 결과 파일 하나만 예외).

## 규칙
- 기준은 두 가지뿐이다. (1) 공식 평가 기준 4항목(적합성 20, AI 적정성 25, 창의성·실용성 30, 윤리·책임성 25)과 그 세부 내용 (2) 사실만 쓴다. 허위는 심사 제외·수상 취소 사유다
- 어느 초안에도 기울지 않는다. 둘 다 나쁘면 그렇게 말한다
- 두 초안의 문장 하나하나를 사실 목록(01)·실제 요청 문장(05)과 맞춰 본다. 사실 목록에 없는 말, 사실보다 센 말, 사실과 어긋나는 말을 모두 찾아 적는다. 작성 기준(04)의 "쓰면 안 되는 것"도 확인한다
- 각 초안 끝의 "작성자 메모"는 작성자가 스스로 밝힌 불확실한 곳이다. 거기 있는 것도 판단하되, 거기 없는 것을 찾는 데 더 힘을 쓴다
- 사실 목록에 없는 일을 한 것처럼 쓰자는 제안은 하지 않는다
- 쉬운 한국어로 쓴다

## 결과 형식
### 1. 결론 (3줄 이내)
A 바탕 / B 바탕 / 둘을 섞음(어느 쪽이 뼈대인지) 중 무엇을 권하는가

### 2. 사실 점검
초안별로: 사실 목록에 없는 말 / 사실보다 센 말 / 사실과 어긋나는 말 / 작성 기준의 금지 표현. 문장을 그대로 인용하고 근거(01이나 05의 어느 항목)를 적는다. 없으면 "없음"

### 3. 평가 항목별 비교
4항목 각각: 심사위원이 이 항목에서 볼 것 → A가 나은 점 / B가 나은 점 → 어느 쪽이 몇 점 정도 더 받을지

### 4. 접수 칸 비교
제목(200자) / 활용한 AI 도구(500자) / 한 줄 소개(200자): 어느 쪽이 나은지와 이유. 글자 수 제한도 확인

### 5. 합칠 때 가져올 것
바탕 초안에 다른 초안에서 가져올 문장·구성 5가지 이내. 어느 부분에 무엇을, 왜. 반대로 가져오면 안 되는 것도 적는다

### 6. 둘 다 놓친 것
평가 기준·작성 기준에 비춰 두 초안 모두 빠뜨린 것, 경쟁작(03)과 비교해 약한 곳

### 7. 예상 점수
초안 A / 초안 B / 권하는 대로 합친 글, 4항목별 점수와 합계 (추정임을 밝힘)
