# 작성 노트 v1 (사례글_초안_v1.md 설명)

> 모두 현재 판단. 초안을 보고 다시 고친다.

## 1. 컨셉

- 핵심 문장: **"고르지 않고 찍기만 한다. 정리는 AI가, 확인은 내가 한다."**
- 핵심 원리: 무엇이 필요한지, 어디를 가릴지 판단하는 일을 **찍는 순간에서 정리하는 순간으로 미뤘다**
- 이야기 틀: 누구나 겪는 장면("이 화면은 필요 없겠지") → 내 상황(실습서) → 방법 → 달라진 점 → 나만의 방식 → 따라 하기·확산
- 책은 출발점이 아니라 **증거**로 둔다 (결과물 단락)

## 2. 평가 항목별 배치

| 평가 항목 (배점) | 본문 위치 | 중점 |
|---|---|---|
| ① 분야 적합성 (20) | 1. 상황 | 예전 방식의 문제 3가지를 구체적으로. 한 번뿐인 단계(에이전트 만들기)로 필요성을 분명히 |
| ② AI 활용 적정성 (25) | 2. 방법 | 도구를 고른 이유(수천 장을 폴더째 읽어야 함), 5단계 절차, 실제 색인 예시, 사람 확인 단계 |
| ③ 창의성·실용성 (30) | 3. 결과, 4. 방식, 5. 따라 하기 | **가장 공을 들인 곳.** 참신성 = 판단 미루기. 실용성 = 한계와 대처. 재현 = 세 단계. 확산 = 매뉴얼·교육 자료·오류 보고 |
| ④ 윤리·책임성 (25) | 2의 4단계, 4의 한계, 6. 안전 | 방법 안에 사람 확인을 넣고, 따로 6절로 한 번 더 모아 심사위원이 찾기 쉽게 함. AI 도움 표기 포함 |

## 3. 중점을 둔 곳과 이유

1. **첫 문장** — 시즌마다 출품작이 많아 제목과 첫 단락에서 눈에 띄어야 함. 기술 용어 없이 누구나 겪는 장면으로 시작
2. **판단 미루기 (4절)** — 다른 사례와 가장 다른 점. 창의성 점수의 중심
3. **실제 색인 예시 (2절)** — "AI가 정리했다"를 말로만 하지 않고 실물로 보여 줌. 책 작업 때 만든 색인(10-10)에서 옮김
4. **한계와 대처 (4절)** — 해 본 사람만 쓸 수 있는 내용. 신뢰와 실용성을 함께 올림. 모두 "제 환경에서"로 한정
5. **시간 수치는 쓰지 않음** — 잴 수 없었다고 먼저 밝히고, 기록의 질 + 체감 + 셀 수 있는 숫자로 대신함

## 5. 사용자 확인 필요

1. **"활용한 AI 도구" 칸**: 지금은 Claude Code만 적음. 캡처 정리에 다른 AI도 썼다면 추가
2. **5절 "이미지를 여러 장 올릴 수 있는 AI라면 시작해 볼 수 있다"**: 대화형 AI 앱에서 직접 해 본 적이 있으면 "할 수 있다"로 강하게 바꿀 수 있음
3. **녹화가 안 된 경우**: 실제로 있었던 일인지, 어떤 상황이었는지 (지금은 일반적으로만 씀)
4. **6절 "서비스 화면은 각 회사의 것임을 밝혔다"**: 책에 상표·화면 출처 안내가 있는지 (있다고 기억하지만 이번에 다시 확인하지 않음)
5. **"실습" 말투**: 딱딱하다는 의견이 있었음. 제목과 첫 단락은 장면으로 시작해 줄였지만, 제목의 "실습"은 그대로 둠. 대안: "다시 할 수 없는 장면도 빠짐없이: …"
6. **접수 화면**: 내용 칸에 표·굵은 글씨가 되는지, 글자 수 제한 (본문 약 3,700자, 공백 빼고 약 2,700자)
7. 책 이름과 링크를 본문에 넣을지 (지금은 "위키독스에 공개"까지만. 넣으면 증거가 강해지지만 서비스 이름이 드러남)
