## 1. 독립 에이전트 4개 관점 (Claude, 초안 v2만 검토)

에이전트에게는 초안 v2와 공모요강만 주고, 아이디어 문서·이전 검토는 주지 않았다. **A·B·C 비교는 하지 않았다** (C는 이 검토 뒤 대화에서 나옴).

| 관점 | 핵심 결과 |
|---|---|
| 심사위원 | 72점 (적합성 15, AI 적정성 19, 창의·실용 18, 윤리 20). 업무 분야 3편 안 가능성 10% 미만, 상위 10~15% 정도 |
| 반대 검토 | [상] 가리지 않은 원본이 외부 AI로 감 / 업무 매뉴얼 확산은 사내 화면을 외부 AI에 올리라는 셈 / "재지 못했다"와 "비교할 수 없을 만큼 빨랐다" 충돌. [중] "빠짐없이" 과장, 책 집필이 업무인지·홍보 의심, 차별점(시나리오 기반 분류, 찍을 시점 알림)을 앞으로, Claude Code 유료·개발 도구라 재현 장벽 |
| 경쟁작 비교 | 시즌3 업무 분야 240편 확인, 19편 정독. 주제가 겹치는 글 없음. 전체 상위 15% 안팎, 수상권 후보 15~25편 중 중위 이하. #1569와 형식·어조 유사도 높음 |
| 일반 독자 | AI가 두 개(시험 대상 서비스, Claude Code)라 헷갈림. "다시 할 수 없는 실습"이 와닿지 않음. 회사 보안·설치·비용 때문에 따라 하기 어려움. 채팅형 AI로 시작하는 부분을 키워 달라 |

공통 지적
- 보안: 원본 화면이 외부 AI로 감 (세 관점이 상위 문제로)
- 효과 수치 없음
- **AI가 틀린 사례와 검증 수치 없음** (경쟁 상위작은 "어긋난 칸 0", "AI가 틀린 5가지" 등이 있음)
- 책 집필이 "업무"로 읽힐지, 수혜자가 1명
- 제목과 "다시 할 수 없는" 설정이 모호함
- 깨진 문장: "하지만 기억이 믿을만 한지."

우리 글에만 있는 것 (경쟁작 비교): 다시 할 수 없는 장면을 지키는 문제의식, 찍을 때 판단을 미루기, AI가 찍을 시점을 알려 줌, 영상에서 장면 추출, 개인정보 AI 1차 + 사람 최종, 결과물이 출간된 책

## 3. Codex CLI 검토 (A·B·C 비교)

원문: [컨셉검토_codex_원문_1023.md](컨셉검토_codex_원문_1023.md)

- 점수 추정: A 75, B 78, **C 82**. C를 업무 생산성으로 추천. 다만 컨셉만 바꿔서는 3편 안에 들기 어렵다
- 보강 제안: 작은 비교 측정, AI 오류 검증(표본 50~100장, 오류가 없으면 검사 범위만), 원본·색인·본문 그림 근거 대응표, 다른 사람 재현 1회, AI의 원고 관여 범위와 "AI에 보내기 전" 개인정보 확인 명시
- 제목 방향: "실습 기록을 AI로 정리해, 설명의 근거를 다시 찾을 수 있는 실습서를 만든 경험"

**주의: "모두 C로 모였다"가 아니다.**
- C를 직접 비교·추천한 것은 Claude(메인 세션)와 Codex 둘뿐. 에이전트 4개는 A만 봤다
- Codex에 준 C 설명을 메인 세션이 써서 C에 유리하게 읽혔을 수 있다
- 확실한 공통 의견은 "효과 수치와 AI 오류 검증이 없다"는 약점 쪽
