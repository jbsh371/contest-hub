# 초안 v4 작성 기준 (2026-10-23, 고정)

> 기준은 두 가지뿐이다. ① 공식 평가 기준 100점 ② 사실만 쓴다(허위는 심사 제외·수상 취소 사유). 체감·취향은 기준이 아니다.
> 방향: 화면 기록 정리법 (업무 생산성). 책은 결과물 하나. 근거는 [사실목록_v1.md](사실목록_v1.md)만.

## 접수 칸
- 공모 분야: 업무 생산성
- 사례 제목(200자): 방식이 보이고 숫자 하나
- 활용한 AI 도구(500자): 첫 줄에 용도("화면 기록 정리")를 먼저. AI가 한 일 / 사람이 한 일 / **AI가 하지 않은 일**(책에 쓸 그림 고르기, 공개 전 최종 확인). 원고 작성에 Claude Code·Codex를 썼다는 한 줄
- 한 줄 소개(200자): 방식 + 규모 + 결과. 테스트 숫자 없음
- 본문: 일반 텍스트, ①~⑤ 소제목 그대로 + "안전하게 쓰기 위해 지킨 것" + "AI를 어디까지 썼는지". 4,000~4,500자

## 항목별로 반드시 들어갈 것
| 평가 항목 | 넣을 것 | 위치 |
|---|---|---|
| ① 적합성 20 | 놓친 화면·기록하느라 멈춤·녹화 못 함·다시 할 수 없는 실습. 끝에 "화면으로 한 일을 단계별로 문서로 남기는 일은 매뉴얼·인수인계·도구 시험 보고에 늘 있다. 실습서 쓰기도 그중 하나" 한 문장. 끝에 "이번에는 찍을 때 고르지 않기로 했다" 한 문장 | ① |
| ② 적정성 25 | 왜 Claude Code(폴더째 맡김). 절차: 시나리오(AI와 함께) → 창 전체 찍기·녹화 → AI가 다음 단계 폴더를 미리 만들고 사람이 넣음, 잘못 넣은 건 AI가 옮김 → 한 줄 요청("캡처 넣었어. 확인해 줘.") → 시간순 읽기·한 줄 메모·빠진 장면·가릴 곳 → 녹화에서 장면 뽑기·모아보기 → 다시 묻기(10-14 원문). 삭제 전 "지우면 다시 못 찍는다" 알림 사례 | ② |
| ③ 창의·실용 30 | 효과는 "할 수 없던 일"부터: 녹화에서 뽑은 1,391장은 예전이면 없었을 기록 → 직접 캡처 636장·녹화 25개가 장면별 폴더로 → 다시 본 것은 모아보기 122장과 책 그림 85장 → 책 출간 → 지금도 블로그·개념 공부에 씀. 그 뒤 테스트 2~3문장, 양쪽 숫자: 손 24분 05초 / AI 47초 + 훑어보기 6분 34초, 고친 곳 0, 공모전 준비 중 사후에 한 작은 비교. 환산은 양쪽 다(손 약 14시간 대 AI 약 4시간)이고 "계산"이라고 밝힘. 오류 검사는 "메모 20장을 다시 보니 모두 맞았다(자세한 것은 아래)" 한 문장만 | ③ |
| ④ 나만의 방식 | 세 가지로 좁힘: 판단을 정리할 때로 미룸 / 시나리오가 지도이고 AI가 찍을 시점을 알려 줌(시나리오는 진행하며 바뀌었고 그때마다 AI와 고침) / 확인은 밖으로 나갈 것에 씀. "원고를 AI가 모아 고침"은 여기 넣지 않음. 한계: Win+G 녹화 안 됨, 다른 프로그램은 글자 흐림(해결 기록 없음), 캡처·녹화 충돌, 녹화 창 잘못 고름, 잘라내기로 캡처 잃음, 폴더 이름 "메일6" 2주 뒤 본인도 모름 | ④ |
| ⑤ 재현·확산 | 4단계. 3단계 앞에 "실제 업무 화면이면 민감한 부분을 먼저 가리고 넘긴다". 채팅형 AI는 "시작해 볼 수 있다"(해 본 적 없음). "다른 사람이 재현한 적은 아직 없다" 밝힘. 확산 3가지(매뉴얼·인수인계 / 새 도구 시험 보고 / 오류 재현 보고)는 "적용할 수 있다"로, 대상을 붙임. 줄이지 않음(700~800자) | ⑤ |
| ④ 윤리 25 | 실습용 계정·가상 인물·가상 도메인 / 결제 화면 녹화 중지 / 가리기 전 원본이 AI 도구로 넘어감(실습용이라 위험 작았음, 실제 업무면 먼저 가릴 것) / 책 그림은 AI가 가릴 곳 찾고 출판 전 사람이 **모두 훑어봄** / 오류 검사 숫자: 60장, 메모 20장 맞음, 영상 장면 15장 글자 읽힘, 책 그림 10장 가림 문제 없음, 폴더 이름만 있는 14장은 판단 못 함, 녹화 실수(사람) 3장 / 화면 출처 표시 | 안전 |
| AI 고지 | 책 구성·문장은 Claude Code가 쓰고 고침, Codex 검토. 기획·시나리오도 AI와 논의. 사용자는 방향·기준, 실습, 전부 읽고 장마다 고칠 곳 짚음, 직접 고치지 않고 AI가 모아 고치게 해 기록을 남김. 이 글도 AI와 함께 썼고 사실 확인은 사용자 | AI 고지, 200자 안팎 |
