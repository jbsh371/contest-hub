## 본문 (게시판 원문 그대로)

대화형 제어 기반 AI를 활용하여 학습 수준 유지, 단계형 진행, 맥락 유지 기능을 갖춘 자기주도 파이썬 학습 시스템을 설계하고 실제 적용한 결과, 학습 중단 없이 코드 작성 능력이 향상되는 효과를 확인한 사례입니다.

① 어떤 상황에서 AI를 활용했나요?
혼자 파이썬을 공부하는 과정에서 두 가지 한계를 반복적으로 경험했습니다.  
첫째, 온라인 강의는 일방향 구조로 인해 궁금한 점을 즉시 해결하기 어려웠고, 일반적인 AI는 내 수준을 고려하지 않은 채 너무 어렵거나 지나치게 단순한 답변을 제공하는 경우가 많았습니다.  
둘째, 장시간 학습 시 AI가 이전 대화 맥락이나 학습 규칙을 유지하지 못해 학습 흐름이 끊기는 문제가 발생했습니다. 이러한 환경에서는 자기주도 학습을 지속하기 어려웠습니다.

② 어떤 AI를 어떻게 활용했나요?
이 문제를 해결하기 위해 단순 질의응답 방식이 아닌, “대화형 제어 기반 AI 자기주도 학습 시스템”을 설계하여 적용했습니다.  
구체적으로는 ChatGPT에 다음과 같은 학습 관리 구조를 프롬프트 형태로 구현했습니다.
- 학습 수준(초급/중급/고급)을 최초 1회 선택하면 이후 모든 설명과 코드 난이도가 동일하게 유지되는 구조  
- 챕터 → 주제 → 코드 실행으로 이어지는 단계형 학습 흐름 구성  
- 숫자 입력(1=진행, 5=심화 등)만으로 학습이 진행되는 제어형 인터페이스 적용  
- 챕터 전환 시 AI가 스스로 학습 규칙과 수준을 재확인하는 맥락 유지 기능 구현  
이를 통해 AI를 단순 도구가 아닌 개인 맞춤형 학습 도구로 활용했습니다.

③ 활용 결과 어떤 변화가 있었나요?
본 시스템을 2주간 하루 평균 1시간씩 실제 학습에 적용한 결과 다음과 같은 변화가 나타났습니다.  
기존에는 반복문(for, while)의 개념 이해가 부족하여 직접 코드를 작성하기 어려웠으나,  
적용 이후에는 반복문과 조건문을 결합한 실습 코드를 스스로 작성할 수 있게 되었습니다.  
또한 기존에는 학습 도중 중단하는 경우가 많았지만,  
수준 맞춤형 설명과 단계형 진행 구조로 인해 학습 흐름이 끊기지 않아 끝까지 학습을 완료할 수 있었습니다.  
초급 학습자는 개념 이해 중심으로, 실무 학습자는 실제 업무형 코드 중심으로 학습이 진행되어 각자의 목적에 맞는 학습 효과를 확인할 수 있었습니다.

④ 나만의 방식 또는 개선 포인트는 무엇인가요?
기존 AI 활용 방식과 차별화되는 핵심은 다음과 같습니다.  

첫째, 숫자 선택 기반 제어 구조입니다.  
복잡한 문장 입력 없이 숫자만 입력하면 다음 단계로 진행되도록 설계하여, 누구나 쉽게 사용할 수 있도록 개선했습니다.  
둘째, 맥락 유지 기능입니다.  
AI가 챕터가 바뀔 때마다 스스로 학습 수준과 규칙을 다시 확인하도록 구성하여, 장시간 학습에서도 일관된 결과를 유지하도록 했습니다.  
이 구조는 일반적인 대화형 AI에서 자주 발생하는 맥락 손실 문제를 보완한 방식입니다.

⑤ 다른 사람도 따라 할 수 있나요?
본 사례는 별도의 프로그램 설치나 복잡한 설정 없이, 프롬프트를 복사하여 입력하는 것만으로 누구나 동일하게 활용할 수 있습니다.  
또한 학습 수준 선택 기능을 통해 학생, 취업준비생, 직장인 등 다양한 사용자가 자신의 수준에 맞게 학습을 시작할 수 있어, 전 국민 누구나 활용 가능한 학습 도구로 확장할 수 있습니다.
